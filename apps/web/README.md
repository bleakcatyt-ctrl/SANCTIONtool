# Cipher Web

Интерактивный интерфейс защищённого мессенджера на React + TypeScript + Vite.

## Запуск

```bash
npm install
npm run dev
```

Из корня репозитория: `npm run dev`.

## Реализовано в демо

- адаптивная Discord-подобная компоновка: серверы, каналы, чат и участники;
- отправка сообщений, реакции, поиск, переключение каналов и серверов;
- состояния микрофона/наушников, модальные окна звонка, безопасности и настроек;
- индикаторы шифрования, проверки подписей и ротации ключей;
- мобильная навигация и доступные интерактивные элементы.

> Это UI-прототип. Тексты о E2EE иллюстрируют целевое поведение и не являются заявлением о криптографической защите демо-данных. До production необходимо подключить аудитированный криптографический протокол и backend.

## Production-архитектура

Рекомендуемая схема описана в [`../../docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md). В production нельзя писать собственную реализацию Signal Protocol или считать transport encryption заменой E2EE.
