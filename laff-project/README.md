# LAFF PROJECT — Форум (Копия Trace RP)

Полная копия форума **forum.trace-rp.com** в стиле XenForo Dark, переименованная под бренд **LAFF PROJECT ☂️**

## 🎨 Что сделано

- **Точная копия дизайна Trace RP**: темная тема XenForo, категории, ноды, треды, посты, сайдбар
- **Все разделы оригинала сохранены**:
  - Главный раздел (Новости, Команда, Обращения)
  - Family War (Семьи, Топ семей)
  - Info (FAQ, Жалобы на игроков/админов)
  - Основные кодексы (Правила сервера, AirDrop, Лидеры, Законы, Уставы)
  - Гос. структуры (GOV, LSPD, LSSD, FIB, EMS, NG)
  - Крайм (Мафии, Банды)
  - Прочее (Маркет, Баги, Идеи)
- **Переименовано**: везде Trace → LAFF PROJECT, IP: play.laff-project.com
- **Функционал**:
  - Поиск по форумам (живой)
  - Создание тем (сохраняется в localStorage)
  - Просмотр тем и ответов
  - Модалки логина/регистрации
  - Онлайн пользователи, статистика, мониторинг сервера
  - Discord виджет
  - Адаптив (мобилы)

## 📁 Структура

```
laff-project/
├── index.html          # Главная - список форумов
├── forum.html?f=...    # Список тем раздела
├── thread.html?id=...  # Просмотр темы
└── assets/
    ├── style.css       # XenForo Dark тема (полный клон)
    ├── app.js          # Логика, мок-данные
    └── logo.png
```

## 🚀 Запуск

```bash
cd laff-project
python3 -m http.server 8000
# открыть http://localhost:8000
```

Или любой статик сервер (Live Server, nginx)
